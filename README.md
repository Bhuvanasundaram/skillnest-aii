# SKILLNEST — KAGE-inspired immersive learning platform

This build updates the Career Alignment / pathway-card page to directly communicate the hackathon problem statement: learner profile, skill-gap analysis, career matching and adaptive learning recommendations.

## Run
- Double-click `START-WINDOWS.bat`, or
- `npm install` then `npm run dev`

- Replaced the shrine/temple imagery in the floating hero preview and three pathway cards with custom SKILLNEST skill-intelligence, career-fit and adaptive-roadmap illustrations.
- Updated section and card copy to explain the learner journey in problem-statement language.
- Preserved the existing Three.js scene/camera code, scroll choreography, card cloth animation, chapter navigation, reveal animations and existing interactions.

The AI-agent and mentor behavior remains the locally simulated prototype described in the existing application.
